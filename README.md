🧮 Calculator App

A sleek, fully functional calculator built with HTML, CSS, and JavaScript. This project features a modern dark theme with a responsive grid layout and smooth user interactions.
✨ Features

    Complete Arithmetic Operations: Addition, subtraction, multiplication, division, and percentage calculations

    Theme Toggle: Switch between Light and Dark modes with a single click (🌙/🔆)

    Keyboard Support: Full numeric keypad functionality

    Responsive Design: Works perfectly on both desktop and mobile devices

    Interactive UI: Haptic feedback with button press animations

    Error Handling: Displays "Error" for division by zero operations

    Memory Functions: Clear (AC) and backspace (⌫) functionality

💻 Technologies Used

    HTML5: Semantic markup structure

    CSS3: Custom styling with animations, grid layout, and responsive design

    JavaScript (ES6): Core logic implementation with event listeners and DOM manipulation


📱 Usage

    Click the number buttons to input digits

    Click operation buttons (+, −, ✖, ÷) to perform calculations

    Press AC to clear the display

    Press ⌫ to delete the last character

    Use % for percentage calculations

    Press = to get the result

    Click the sun/moon button (🔆/🌙) to toggle themes
